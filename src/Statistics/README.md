# Statistics Module

This directory contains statistical and random-number utilities used by the RF-EMT toolkit.

| File | Description |
| --- | --- |
| `GMS_arma_estimation.cpp` | Implements ARMA parameter estimation algorithms and numerical fitting routines. |
| `GMS_arma_estimation.h` | Declaration of ARMA estimation interfaces, types, and helper methods. |
| `GMS_arma_model.cpp` | Defines the ARMA model implementation and model-related computations. |
| `GMS_arma_model.h` | Declares the ARMA model structures and public API. |
| `GMS_bayesian_estimate.cpp` | Implements Bayesian estimation procedures and posterior computations. |
| `GMS_bayesian_estimate.h` | Declares Bayesian estimation interfaces and data structures. |
| `GMS_descriptive_statistics.h` | Provides descriptive statistical summaries such as moments, quantiles, and distributions. |
| `GMS_descriptive_statistics.hpp` | Header-only implementation of descriptive statistics utilities. |
| `GMS_kde_fft.cpp` | Implements kernel density estimation using FFT-based methods. |
| `GMS_kde_fft.h` | Declares KDE FFT functions and related types. |
| `GMS_kmeans.cpp` | Implements the k-means clustering algorithm and related logic. |
| `GMS_kmeans.h` | Declares k-means data structures and public methods. |
| `GMS_kmeans_wrapper.h` | Wraps k-means functionality for easier integration with higher-level code. |
| `GMS_mkl_betarng.cpp` | Generates beta-distributed random values using Intel MKL. |
| `GMS_mkl_betarng.h` | Header for beta random number generation utilities. |
| `GMS_mkl_cauchyrng.cpp` | Generates Cauchy-distributed random values using Intel MKL. |
| `GMS_mkl_cauchyrng.h` | Header for Cauchy random number generation utilities. |
| `GMS_mkl_exponentialrng.cpp` | Generates exponential-distributed random values using Intel MKL. |
| `GMS_mkl_exponentialrng.h` | Header for exponential random number generation utilities. |
| `GMS_mkl_gaussianrng.cpp` | Generates Gaussian-distributed random values using Intel MKL. |
| `GMS_mkl_gaussianrng.h` | Header for Gaussian random number generation utilities. |
| `GMS_mkl_gumbelrng.cpp` | Generates Gumbel-distributed random values using Intel MKL. |
| `GMS_mkl_gumbelrng.h` | Header for Gumbel random number generation utilities. |
| `GMS_mkl_laplacerng.cpp` | Generates Laplace-distributed random values using Intel MKL. |
| `GMS_mkl_laplacerng.h` | Header for Laplace random number generation utilities. |
| `GMS_mkl_lognormalrng.cpp` | Generates log-normal random values using Intel MKL. |
| `GMS_mkl_lognormalrng.h` | Header for log-normal random number generation utilities. |
| `GMS_mkl_rayleighrng.cpp` | Generates Rayleigh-distributed random values using Intel MKL. |
| `GMS_mkl_rayleighrng.h` | Header for Rayleigh random number generation utilities. |
| `GMS_mkl_uniformrng.cpp` | Generates uniform random values using Intel MKL. |
| `GMS_mkl_uniformrng.h` | Header for uniform random number generation utilities. |
| `GMS_mkl_weibullrng.cpp` | Generates Weibull-distributed random values using Intel MKL. |
| `GMS_mkl_weibullrng.h` | Header for Weibull random number generation utilities. |
| `GMS_nonparametric_statistics.c` | Implements nonparametric statistical methods and tests. |
| `GMS_nonparametric_statistics.h` | Declares nonparametric statistics interfaces and helpers. |
| `GMS_normality_test.cpp` | Implements tests for checking whether sample data follows a normal distribution. |
| `GMS_normality_test.h` | Declares normality test interfaces and result types. |
| `GMS_normality_test_v2.cpp` | Alternative or updated normality test implementation. |
| `GMS_normality_test_v2.h` | Header for the second-generation normality test API. |
| `GMS_pdf_kernels_scalar.h` | Scalar implementations of probability density kernels. |
| `GMS_pdf_kernels_sse.h` | SSE-optimized implementations of probability density kernels. |
| `GMS_random.h` | Core random number generation utilities and distributions. |
| `GMS_statistical_analysis.c` | General statistical analysis routines in C. |
| `GMS_statistical_analysis.h` | Declares generic statistical analysis functions and structures. |
| `GMS_svrng_wrappers.cpp` | Wraps stochastic vector random number generation routines. |
| `GMS_svrng_wrappers.h` | Declares wrapper interfaces for SVRNG-based random generation. |
| `GMS_uniform_distribution.h` | Implements uniform distribution utilities and related helper logic. |
